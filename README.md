# La-nouvelle-fran-ais-crite-simplifi-e
Ce document présente une proposition de réforme et de simplification de l'écriture du français conçue pour rendre l'apprentissage plus naturel, fluidifier la lecture et éliminer durablement les fautes d'orthographe les plus fréquentes.
